# ♾️ InfinityOS

**Visually nostalgic. Internally modern.**

## About

InfinityOS is an open-source Android ROM project focused on longevity, customization, experimentation, and giving older devices a new life.

The project initially builds on the work of **LineageOS and AOSP**, while progressively developing its own identity, features, visual experience, and technologies.

InfinityOS is not intended to recreate Android from scratch. Instead, the goal is to evolve from a strong open-source foundation and gradually make the experience increasingly its own.

## Current Status

InfinityOS is currently in early development.

Current progress includes:

* LineageOS 22.2 / Android 15 successfully built for the **Moto G42 (`hawao`)**.
* Custom InfinityOS boot animation.
* Custom InfinityOS wallpaper.
* Initial SystemUI customization in development.
* Dedicated development and build environment established.
* Initial work toward creating an independent InfinityOS identity and ecosystem.

The project is experimental and should not be considered a production-ready ROM yet.

## Features

Planned and experimental features include:

* Custom InfinityOS SystemUI.
* Custom Quick Settings experience.
* Custom Settings experience.
* InfinityOS-specific visual design.
* Custom icons, animations, colors and interface elements.
* Experimental InfinityOS features.
* Performance and longevity improvements for older devices.
* A nostalgic visual experience combined with modern Android internals.
* Progressive development of original InfinityOS components and technologies.

Features will be introduced progressively as development continues.
